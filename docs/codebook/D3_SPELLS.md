## Processing Steps

| Step number | Action                                                                                                                                                                                            |
| ----------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Step 1      | If missing `OBSERVATION_PERIODS:op_end_date ` AND  `OBSERVATION_PERIODS:op_start_date ` < `end_study_date`, impute `OBSERVATION_PERIODS:op_end_date ` with `config_values:end_study_date` |
| Step 2      | Exclude observation periods that have missing both start and end dates                                                                                                                            |
| Step 3      | Creation of spells (instructions available in the `rule_of_calculation` column in the table above.)                                                                                             |
| Step 4      | Inner Join of PERSONS and SPELLS                                                                                                                                                                 |
|             | We correct the start of the spell checking if this is before the `birth_date` of a person, if that's the case then `start_spell` is = `birth_date`                                         |                                                         |
| Step 5      | We correct the end of the spell checking if this is empty and the start_spell is before the study date, if that's the case then `end_spell` = `end_study_date`                                |
| Step 6      | Create columns `with_start_and_end` and `start_before_end` following the codebook description                                                                                                      |
| Step 7      | Selection of spells that have `with_start_and_end` and `start_before_end` = `true`                                                                                                        |
