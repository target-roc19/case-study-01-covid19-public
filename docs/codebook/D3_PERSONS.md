## Processing Steps

Apply record imputation: day/month of birth, day/month of death

| Step number | Action                                                                                                                                                                                                                                                                                                      |        |               |                       |
| :---------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ------------- | --------------------- |
|   Step 1    | Follow the rule_of_calculation column from the table above to create the following columns:<br />`sex_at_instance_creation`, `imputed_birth_day`,  `imputed_birth_month`, `imputed_death_day`,  `imputed_death_month`, `missing_year_of_birth`, `not_missing_year_death`, `missing_sex` and `year_of_birth` |        |               |                       |
|   Step 2    | If `imputed_birth_day = TRUE`, then impute  `day_of_birth `with the number `16`.                                                                                                                                                                                                                            |        |               |                       |
|   Step 3    | If `imputed_birth_month = TRUE`, then impute  `month_of_birth `with the number `6`.                                                                                                                                                                                                                         |        |               |                       |
|   Step 4    | If `imputed_birth_month = TRUE` & `day_of_birth = 31`, impute `month_of_birth` with the number `5`.                                                                                                                                                                                                         |        |               |                       |
|   Step 5    | If `imputed_death_day = TRUE`, then impute  `day_of_death `with the number `16`.                                                                                                                                                                                                                            |        |               |                       |
|   Step 6    | If `imputed_death_month = TRUE`, then impute  `month_of_death ` with the number `6`.                                                                                                                                                                                                                        |        |               |                       |
|   Step 7    | If `imputed_death_month = TRUE` & `day_of_death = 31`, impute `month_of_death` with the number `5`.                                                                                                                                                                                                         |        |               |                       |
|   Step 8    | Follow the rule_of_calculation column from the table above to create the rest of the columns:<br />`birth_date`, `death_date`, `death_before_birth` and `born_60y_before_end_study_period`.                                                                                                                 |        |               |                       |
|   Step 9    | Stepwise record removal:                                                                                                                                                                                                                                                                                    | Remove | Left          | N-original no of rows |
|     9.1     | Remove rows missing `year_of_birth`                                                                                                                                                                                                                                                                         | n1     | N1:= N-n1     |                       |
|     9.2     | Remove rows with missing year of death when day/month of death are available                                                                                                                                                                                                                                | n2     | N2:= N1-n2    |                       |
|     9.3     | Remove rows with death date before birth date                                                                                                                                                                                                                                                               | n3     | N3:= N2-n3    |                       |
|     9.4     | Remove rows with duplicated `person_id`                                                                                                                                                                                                                                                                     | n4     | N4:= N3-n4    |                       |
|     9.5     | Remove rows with missing sex                                                                                                                                                                                                                                                                                | n5     | N5:= N4-n5    |                       |
|     9.6     | Remove dead people before start study period                                                                                                                                                                                                                                                                | n6     | N6 := N5 - n6 |                       |
|     9.7     | Remove people less than 16 years of age one day before study end date                                                                                                                                                                                                                                       | n7     |               |                       |
