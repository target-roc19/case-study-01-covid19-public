## Metadata


| Table name                | D4_StudyCohortFup`<Main/Supplementary>`                                                                                                         |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Description               | Follow-up information for the study cohort: censoring dates, outcome events and derived follow-up time for estimands 1 and 2.                   |
| Source                    | D4_StudyCohort`<Main/Supplementary>`; D3_PERSONS; D3_SPELLS; anchoR anchored AESI variables (anchoring_window_metadata.csv); config_values.yaml |
| Step                      | transformations/T3_study_design/source_code/create_fup.R (consumed by transformations/T4_statistical_analysis/source_code/create_fup_table.R)   |
| Content                   | Censoring dates, follow-up time and outcome event indicators                                                                                    |
| Population                | Selected study cohort (group EXPOSED or CONTROL; UNMATCHED removed)                                                                             |
| Unit of Observation (UoO) | person (per match) in the study cohort                                                                                                          |
| Output                    | data/D4_analytic_datasets/D4_StudyCohortFupMain.parquet and D4_StudyCohortFupSupplementary.parquet                                              |

Notes:

1. Follow-up starts at T0 and ends at the earliest listed date; the maximum is T0 + 90 days (max_fup_date).
2. Tie rule: if several variables share the minimum date, reason_censoring is the first in the list order used in create_fup.R (covid_date, death_date, loss_to_follow_up, max_fup_date, end_study_date, end_data_collection, ie3 variables, ie5_prep_treatment).
3. Observed reason_censoring_est1 values in D4_StudyCohortFupMain.parquet (13,592 rows): covid_date 11,195; death_date 2,374; end_study_date 8; ie5_prep_treatment 8; loss_to_follow_up 4; max_fup_date 3. No ie3 or end_data_collection values were observed.
4. Estimand 2 population: create_fup_table.R keeps CONTROL plus EXPOSED with compliant_exposed == TRUE. The parquet holds all rows.
5. ie1_missed_second_dose_target_exposed and fup_length_months_est1/est2 are created in create_fup_table.R and are not in this parquet.
6. Data quality: 2,380 of 13,592 rows have fup_length_days_est1 < 1 because end_fup falls before T0 (for example death_date in 2019 or end_study_date before T0). Needs review.

## Estimand-specific Rules

### Estimand 1

Follow-up ends at the earliest of:

* composite_outcome (covid_date or death_date, whichever is first)
* loss_to_follow_up
* max_fup_date
* end_study_date
* end_data_collection
* ie3_first_dose_covid_nontarget_exposed (hypothetical)
* ie3_first_dose_covid_any_control (hypothetical)
* ie5_prep_treatment (hypothetical)

### Estimand 2

Follow-up ends at the earliest of:

* covid_date (outcome)
* death_date (censoring; see open questions)
* loss_to_follow_up
* max_fup_date
* end_study_date
* end_data_collection
* ie3_first_dose_covid_nontarget_exposed (hypothetical)
* ie3_first_dose_covid_any_control (hypothetical)
* ie5_prep_treatment (hypothetical)
