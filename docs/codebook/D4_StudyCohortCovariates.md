## Notes

### General notes:

* Assessment windows are relative to T0. Variables in the output take their windows from anchoring_window_metadata.csv; draft-only variables keep the draft windows.

### Implementation notes:

* We have two populations (Main analysis and Supplementary analysis). They may contain different matches but a large fraction of the spells will be shared across them. We may consider creating a single lookup for unique person_id + T0 across the two analyses, compute the baseline covariates for these unique spells, and then save (a) a single file for the lookups or (b) already two separate files for Main and Supplementary analyses.
